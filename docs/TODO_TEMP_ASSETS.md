> видно по цвету: доминирующий цвет тайла травы — **RGB(173, 188, 58)** (среднее
> по тайлу RGB(172.1, 187.6, 57.9)) вместо прежних RGB(74, 108, 62). Тайл дерева
> в паке нарисован на пустом фоне (118 прозрачных пикселей из 256, оба крайних
> столбца пустые), поэтому он лежит на сплошной тёмной подложке RGB(26, 48, 30),
> а куст поверх неё затемнён на 25 % — все четыре тайла на 100 % непрозрачны,
> чёрных квадратов вокруг деревьев больше нет. Прежнее утверждение, что края
> дерева «совпадают с травой», при повторном замере оказалось ложным: по
> крайним столбцам совпадает 0 пикселей из 16 (по тайлу целиком — 0 из 256),
> потому что под кустом тёмная подложка, а не трава. Выглядит это как обводка
> куста, а не как шов наложения: тёмный тайл (61.9 по Rec.601) контрастирует со
> светлой травой зоны (167.5). Размеры и имена сохранены, игровой код не
> менялся. Скрипт идемпотентен: повторный запуск даёт побайтово те же PNG.

58 файлов в `assets/sprites/`, и их контракт размеров. У каждого из 23 врагов и
боссов собственный спрайт `enemy_<type>.png` 16×16 из `Actor/` пака, у каждого
из 9 именованных NPC собственный `npc_<speaker_id>.png` 16×16 из
`Actor/Character/` — перезатонированных заглушек среди актёров не осталось;
зональный оттенок тела и обводка силуэта — сознательная обработка читаемости
поверх реального арта. Базовые файлы:

| Файл | Размер | Что изображает |
| --- | --- | --- |
| `player.png` | 64x16 (4 кадра) | герой: вниз / вверх / вбок / резерв |
| `chest.png` | 16x16 | сундук |
| `potion.png` | 16x16 | настой |
| `coin.png` | 8x8 | монета |
| `tiles.png` | 64x16 | трава, земля, камень, дерево |
| `tiles_forest/ruins/dungeon/fortress.png` | 64x16 | зональные атласы пола |
| `enemy_*.png` (23 файла) | 16x16 | каждый враг и босс — свой арт из `Actor/` |
| `npc_*.png` (9 файлов) | 16x16 | каждый именованный NPC — свой арт из `Actor/Character/` |
| `wolf.png`, `archer.png`, `npc.png` | 16x16 | легаси: игровой код их больше не использует |

Плюс четырнадцать иконок предметов `icon_<id>.png` 16×16 — по одной на каждый
предмет из `data/items.json`; в таблице выше их нет, потому что это не спрайты
мира, а UI.

Генератор `tools/gen_sprites.py` оставлен как запасной вариант: он умеет
восстановить прежние процедурные картинки, если пака под рукой не окажется, и в
текущей сборке не участвует.

Что **осталось** временным — у этих сущностей своего файла нет: они едят чужой
спрайт, рисуются кодом или берутся из системы. Врагов и NPC в этом списке
больше нет: у всех 23 врагов и боссов и всех 9 именованных NPC собственные
спрайты из пака. Подробности по каждой строке — в абзацах ниже.

| Что | Где | Чем сейчас является |
| --- | --- | --- |
| Завал | `scenes/world/breakable.tscn` | `ColorRect` 16×16 цвета `Color(0.44, 0.41, 0.38)` |
| Дверь руин | `scripts/world/ruin_door.gd` | рисуется кодом в `_draw()`, ни `Sprite2D`, ни файла |
| Рычаг | `scripts/world/mechanism.gd` | рисуется кодом в `_draw()`, ни `Sprite2D`, ни файла |
| Находка `PickupHerb` | `scripts/world/forest.gd` | ест `potion.png` из `scenes/items/pickup.tscn`, хотя поднимает `wolf_fang`: картинка врёт о том, что лежит в траве. `PickupCoin` с 2026-11-23 называет `coin.png`, `PickupFlask` рисует настой честно — иконка подставляется через `texture_path` у `pickup.gd`, так что для клыка достаточно строки в `forest.gd` |
| Шрифты | `SystemFont` | системные шрифты ОС (`Helvetica Neue → Arial Unicode MS → Arial → DejaVu Sans`), не встроенные в игру; сглаживание и субпиксельное позиционирование выключены в обеих темах (`hud.gd`, `main_menu.gd`). Пиксельной остаётся только растеризация, сам шрифт — пропорциональный и платформозависимый: в локальных архивах пиксельного шрифта с кириллицей нет (замер — `docs/ASSET_CREDITS.md`) |

Раньше в этом списке жили кабан, огонёк, Хранитель леса, костяной стражник и
скелет-лучник — все пятеро ели `wolf.png`/`archer.png` с оттенком. С приходом
отдельных спрайтов из `Actor/` пака (`enemy_ash_boar.png`,
`enemy_ash_wisp.png`, `enemy_forest_warden.png`, `enemy_ruin_skeleton.png`,
`enemy_ruin_skeleton_archer.png` и ещё восемнадцать) этот пункт закрыт: у
каждого врага свой арт, а зональный оттенок и обводка — только обработка
читаемости поверх него.

У завала (`scenes/world/breakable.tscn`) спрайта тоже нет: это `ColorRect` 16x16
цвета `Color(0.44, 0.41, 0.38)` под узлом `Visual`. При разрушении он просто
скрывается — без анимации, без обломков и без частиц. Новых файлов в
`assets/sprites/` из-за него не появилось, но замена ниже должна закрыть и его:
читаемый силуэт булыжника вместо серого квадрата.

У двери и рычага руин (`scripts/world/ruin_door.gd`,
`scripts/world/mechanism.gd`) спрайтов нет вовсе: оба рисуются кодом в `_draw()`
— плита в каменной раме с замочной скважиной у одной и скоба с опущенным или
поднятым рычагом у другого. Это самые простые заглушки проекта: ни `Sprite2D`, ни
отдельного файла сцены за ними нет, узел собирается кодом в `_spawn_actors()`
той же зоны, поэтому замена — нарисованный тайл плюс `Sprite2D`, а не
переписывание логики.
