# Временные ассеты

Вся графика в `assets/sprites/` сгенерирована скриптом
`tools/gen_sprites.py` (чистый Python, без зависимостей). Это **заглушки**,
а не финальный арт: их задача — чтобы силуэты читались и механики можно было
проверять.

| Файл | Размер | Что изображает |
| --- | --- | --- |
| `player.png` | 64x16 (4 кадра) | герой: вниз / вверх / вбок / резерв |
| `wolf.png` | 16x16 | пепельный волк |
| `archer.png` | 16x16 | культист с луком |
| `npc.png` | 16x16 | Эдрик |
| `chest.png` | 16x16 | сундук |
| `potion.png` | 16x16 | настой |
| `coin.png` | 8x8 | монета |
| `tiles.png` | 64x16 | трава, земля, камень, дерево |

У кабанов и огоньков (`scenes/enemies/boar.tscn`, `scenes/enemies/wisp.tscn`)
своих спрайтов нет: кабан — это `wolf.png` с оттенком
`sprite_tint = Color(1, 0.72, 0.55)`, огонёк — `archer.png` с оттенком
`Color(0.65, 0.85, 1)`. У Хранителя леса (`scenes/enemies/forest_warden.tscn`)
тоже `wolf.png`, но с оттенком `Color(0.55, 0.85, 0.6)` и без отдельного
силуэта — размером он волка больше только коробочкой коллизии (18x14 против
12x10), на картинке это тот же спрайт 16x16. Оттенок задан в самой сцене, новых
файлов в `assets/sprites/` не появилось, и замена ниже должна закрыть уже четыре
типа врагов плюс мини-босс, а не два.

У завала (`scenes/world/breakable.tscn`) спрайта тоже нет: это `ColorRect` 16x16
цвета `Color(0.44, 0.41, 0.38)` под узлом `Visual`. При разрушении он просто
скрывается — без анимации, без обломков и без частиц. Новых файлов в
`assets/sprites/` из-за него не появилось, но замена ниже должна закрыть и его:
читаемый силуэт булыжника вместо серого квадрата.

## Что заменить перед релизом

1. Выбрать единый CC0-набор (кандидат — Ninja Adventure, см. ТЗ раздел 3.1).
2. Сверить ракурс, палитру и размер тайла с текущей сеткой 16x16.
3. Заменить спрайты и тайлсет, обновить `ASSET_CREDITS.md`. Сюда же — тайл
   завала вместо `ColorRect` в `scenes/world/breakable.tscn`.
4. Убрать этот файл и пометку о заглушках из README.

Анимации ходьбы сейчас нет — кадр выбирается по направлению взгляда. Это
осознанное упрощение среза, а не забытая функция.
