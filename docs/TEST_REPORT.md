# Отчёт о тестировании

Дата: 2026-11-18. Движок: Godot `4.7.2.stable.official.ed1daf0bf`.
Все команды выполнены реально, вывод скопирован из терминала.

## 1. Чистый запуск сцены

```
$ godot --headless --path . --quit-after 120 2>&1 | grep -cE 'ERROR|SCRIPT ERROR'
0
```

120 кадров основной сцены без единой строки `ERROR` / `SCRIPT ERROR`.

## 2. Юнит- и интеграционные тесты

```
$ godot --headless --path . --script res://tests/test_core.gd
checks: 43  failures: 0
exit=0
```

Покрыто:

| Группа | Проверки |
| --- | --- |
| DamageResolver | первый удар применяется; повторный `hit_id` — нет; HP снижается один раз |
| GameState | стеки инвентаря, удаление, запрет снять больше, чем есть; level-up; золото и запрет перерасхода |
| Save/Load | round-trip слота 2 (золото, инвентарь, экипировка, HP, квест), битый слот отклоняется с ошибкой |
| Квесты | старт, готовность после убийств, награда ровно один раз, повторная сдача отклонена |
| Враги | дальний враг реально стреляет снарядом; ближний показывает телеграф, хитбокс не открыт постоянно |
| Сцена | `main.tscn` грузится, игрок есть, ≥2 врагов, ≥2 интерактивных объекта |

Тесты запускались три раза подряд — 0 провалов каждый раз (не флапают).
BOT-002 (самый длинный сценарий) прогонялся три раза — `PASS` каждый раз.

## 3. Отладочный бот

| Сценарий | Что проверяет | Результат |
| --- | --- | --- |
| BOT-001 | дойти до NPC, взять квест | `PASS (reached_npc; quest_state=active)` |
| BOT-002 | взять квест → убить 3 волков → вернуться → сдать | `PASS (attacks=26; progress=3/3; state=done; gold=18->78)` |
| BOT-008 | убить врага в бою | `PASS (attacks=28; kills={"ash_wolf": 3})` |
| BOT-009 | save → изменить состояние → load | `PASS (saved; gold=7 hp=100)` |
| BOT-010 | soak ~75 с: движение по карте, бои, лечение | `PASS (segments=43; hp=92/100; kills={"ash_wolf": 1})` |
| BOT-011 | намеренно подставиться под удар | `PASS (hp=100->92)` |

Бот ходит через `InputSource`, то есть тем же путём, что человек: без
телепортов и без чтения приватного состояния врагов.

## 4. Визуальная проверка

Скриншоты сняты из реального окна (`PEPEL_SCREENSHOT`), не из headless:

- игровой мир: карта 52x32, дорога, поляна, деревья с коллизией;
- HUD: HP/MP/XP, уровень, золото, трекер задания, подсказка управления;
- диалог Эдрика;
- инвентарь с надетым мечом и расходниками.

Дефекты, найденные по скриншотам и исправленные: обрезанный правый блок HUD,
обрезанная подсказка, слишком большой пустой инвентарь, мелкая карта.

## 5. Что не проверено

- Живой геймплей мышью и клавиатурой человеком — это делает пользователь.
- Производительность на слабом железе.
- Экспорт в Windows.
- Длительный soak больше 75 секунд.
