# Сборка под Windows

Дата: 2026-11-19. Движок: Godot `4.7.2.stable.official.ed1daf0bf`, macOS arm64.

## Статус

Пресет `Windows Desktop` подготовлен в `export_presets.cfg` и **проверен**:
Godot его читает и принимает. Сборка **не выполнена**, ни одного `.exe` на диске
нет — её просто ни разу не запускали.

**Блокеров для сборки нет.** Шаблоны экспорта Godot `4.7.2.stable` установлены:
каталог `~/Library/Application Support/Godot/export_templates/4.7.2.stable/`
существует, его `version.txt` содержит `4.7.2.stable`, внутри лежат
`windows_release_x86_64.exe`, `windows_debug_x86_64.exe`, console-варианты,
`macos.zip` и шаблоны остальных платформ. Проверено `ls` 2026-11-25.

Текст ниже — **запись прогона 2026-11-19**, когда шаблонов действительно не
было. Она оставлена как история: на текущей машине эта ошибка не воспроизводится,
и повторять её как доказательство нельзя.

```
$ godot --headless --path . --export-release "Windows Desktop" /tmp/pepl_probe.exe
ERROR: Cannot export project with preset "Windows Desktop" due to configuration errors:
Шаблоны экспорта не найдены по ожидаемому пути:
~/Library/Application Support/Godot/export_templates/4.7.2.stable/windows_release_x86_64.exe
ERROR: Project export for preset "Windows Desktop" failed.
```

Ошибок «пресет не найден» или «неизвестный параметр пресета» там нет — падение
было только на отсутствии шаблонов. Код возврата Godot — `1`. Сам экспорт после
установки шаблонов **не выполнялся и не проверялся**: утверждать, что сборка
проходит, пока нет собранного `.exe` и запуска собранной игры, нельзя.

## Что нужно установить

Шаблоны экспорта **ровно той же версии, что и редактор** — `4.7.2.stable`
(набор от 4.7.1 или 4.7.3 не подойдёт: Godot ищет каталог по имени версии).
Размер — порядка 1 ГБ. Godot ждёт их здесь:

```
~/Library/Application Support/Godot/export_templates/4.7.2.stable/
```

На 2026-11-25 каталог `4.7.2.stable/` **уже заполнен** — шаблоны скачаны и лежат
по ожидаемому пути, так что пункты 1 и 2 ниже выполнять не нужно. Они оставлены
как инструкция для чистой машины, где шаблонов нет:

1. **Редактор (рекомендуется).** `Editor` → `Manage Export Templates` →
   `Download`: Godot сам скачает набор, соответствующий своей версии.
2. **Официальный архив релиза.** На странице релиза тега `4.7.2-stable`
   (официальные релизы Godot на GitHub) лежит архив стандартного имени
   `Godot_v4.7.2-stable_export_templates.tpz` — zip с другим расширением.
   Внутри каталог `templates/` с файлами вида `windows_release_x86_64.exe`;
   его содержимое копируется **внутрь** каталога `4.7.2.stable/`, который
   нужно создать вручную.

**Честно:** этот проект шаблоны не скачивал. В текущем окружении установка
невозможна без решения владельца — это ~1 ГБ трафика и запись в каталог
пользователя вне репозитория. Подмены шаблонами другой версии и «имитации
сборки» здесь нет.

`wine`, `rcedit`, .NET и Mono для **сборки** не нужны: экспорт Windows в
Godot 4 — это подстановка готового бинарника из шаблона, а не
кросс-компиляция, и ресурсами `.exe` движок управляет сам. `wine` понадобится
только чтобы запустить готовый `.exe` на macOS или Linux.

## Команда сборки

```bash
mkdir -p build/windows
godot --headless --path . --export-release "Windows Desktop" build/windows/pepl.exe
```

`build/` и `dist/` в `.gitignore` — артефакты в репозиторий не попадают.
Пресет пишет `.pck` отдельно (`binary_format/embed_pck=false`), поэтому нужны
оба файла: `pepl.exe` и `pepl.pck`.

## Что проверить после успешной сборки

1. `ls -l build/windows/` — `pepl.exe` есть, размер правдоподобный (десятки
   мегабайт, не килобайты), рядом `pepl.pck`.
2. Скопировать на Windows **всю** папку целиком, обоими файлами, запустить
   `pepl.exe`.
3. Окно 1440x810 при viewport 480x270 (в `project.godot` стоит window
   override); картинка не размытая, пиксели целые.
4. Управление: W A S D / стрелки, ЛКМ — атака, Space — рывок, E — взаимодействие,
   I — инвентарь, J — журнал, M — карта, 1–4 — быстрые слоты, F5/F9 —
   сохранение и загрузка, Esc — пауза.
5. Стартовый квест проходится (Эдрик → три волка → сдача, награда один раз),
   а сохранение переживает перезапуск: F5, закрыть, запустить, F9.

Если после установки шаблонов команда снова падает — читать вывод целиком:
текст ошибки укажет, какого файла не хватает или какой параметр не принят.
